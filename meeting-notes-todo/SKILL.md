# 會議筆記 → Excel 待辦清單

把零散的會議筆記整理成一份可以直接追蹤的 Excel 待辦清單。交付物永遠是 `.xlsx`，不要只在對話裡列表格。

## 欄位（照這個順序，名稱不可改）

| 欄 | 內容 | 規則 |
|---|---|---|
| 事項 | 要做的事，一句話 | 去掉「某人：」這種前綴，人名放到負責人 |
| 負責人 | 人名 | 筆記沒寫、或寫「未定／負責人未定／TBD」→ 一律填 `待指派` |
| 期限 | 日期 | `YYYY-MM-DD`。真的沒寫就留空，**不要填假日期或「待定」** |
| 狀態 | 進度 | 只能是：未開始、進行中、已完成、延後、已排定 |

## 日期換算

先確定基準日：使用者給了會議日期就用會議日期，否則用今天。用程式確認星期幾，不要心算。

- 「下週三」：以基準日所在週的週一為本週起點，下週三 = 下一個週一 + 2 天。基準日當天已過的星期，取再下一週。
- 「這週五」「本週五」：基準日所在週的星期五；若已過，在整理說明裡標出來，不要默默往後推。
- 「月底」「月底前」：基準日所在月份的最後一天。
- 「下個月底」：下個月的最後一天。
- 只寫星期幾（如「改到週四」）：取基準日之後的下一個該星期，並在整理說明註明這是推斷。
- 時間（「早上十點」）寫進事項文字，期限欄只放日期。

## 狀態怎麼填

- 筆記明確寫「延後／延期／暫停／等某某」→ `延後`
- 是會議或行程本身改期、已約好 → `已排定`
- 筆記寫了進度（做到一半、進行中）→ `進行中`
- 筆記寫已完成、已交、已寄出 → `已完成`
- 其餘沒寫進度的 → `未開始`

## 排序

依期限由近到遠。沒有期限的放最後。同一天依筆記出現順序。

## 工作簿結構

兩個工作表，第一個是 `待辦清單`，第二個是 `整理說明`。

### 待辦清單

- 第 1 列：標題「會議待辦清單」，合併 A1:D1。
- 第 2 列：一行副標，寫整理日期、基準日，以及「假設見整理說明」。
- 第 4 列：欄位標題。第 5 列起是資料。
- 凍結在 A5，讓標題列固定。套上自動篩選。
- 期限欄格式 `YYYY-MM-DD`，內容是真正的日期，不是文字。
- 每個推斷過的期限儲存格加註解，寫這格是怎麼來的。
- 狀態欄加下拉選單，範圍拉到第 104 列，選項：`未開始,進行中,已完成,延後,已排定`。
- 右側 F、G 欄放彙總，**用公式，不要寫死數字**：
  - 事項合計 `=COUNTA(A5:A104)`
  - 待指派 `=COUNTIF(B5:B104,"待指派")`
  - 其餘每個狀態各一列 `=COUNTIF(D5:D104,"狀態名")`
  - 範圍故意拉到 104 列，使用者在下方新增事項會自動計入。
- 彙總下方加一行小字，說明新增事項的方式，以及篩選範圍目前只套在既有資料上。
- 條件化格式（套到第 104 列，這樣之後改狀態顏色會跟著變）：
  - `待指派`：淡琥珀色底、深棕字
  - `未開始`：淡灰底
  - `進行中`、`已排定`：淡藍底
  - `已完成`：淡綠底
  - `延後`：淡琥珀色底

### 整理說明

用表格列出每一項判斷，欄位是「項目」與「判斷」。至少包含：基準日與星期幾、每一個相對日期怎麼換算、哪些負責人是填「待指派」、每個狀態為什麼這樣標、排序方式。最後附上筆記原文，方便使用者對回來源。

## 版面

- 字型全程 Arial。
- 不要格線；標題列用深藍底白字（`1F3A5F`）。
- 欄寬要夠：事項約 36、負責人 14、期限 16、狀態 12。列高讓文字不擠。
- A4 直向、符合頁寬、頁首頁尾、列印範圍含彙總。中文內容不要讓欄位被截斷。
- 檔名：`會議待辦清單.xlsx`。若使用者給了會議名稱或日期，改成 `會議待辦清單-YYYY-MM-DD.xlsx`。

## 做法

1. 用 Python 算出基準日的星期幾與每個換算後的日期，用 `assert` 驗證星期幾，不要手算後直接寫死。
2. 用 openpyxl 產出工作簿。公式寫成公式字串，不要把算好的數字填進去。
3. 只要工作簿含公式，就必須重算：`python <xlsx skill>/scripts/recalc.py 輸出檔.xlsx`，確認 `status` 是 `success` 且 `total_errors` 為 0。
4. 重算後用 `data_only=True` 讀回，核對彙總數字與列數、負責人數一致，期限是日期不是文字。
5. 重算會把含中文儲存格的字型改成環境預設字型。重算完後直接改 `xl/styles.xml`，把所有 `<name val="...">` 改回 `Arial`，不要再次用 openpyxl 存檔（那會清掉公式的快取值），也不要再重算一次。

## 交付時要說的話

簡短說明：幾筆、基準日、哪些日期是推算的、哪些填了「待指派」、哪些期限留空。不要逐條複述清單內容，使用者看得到檔案。
